# DevOps Internship Task 4 - Git Workflow

## Overview
This project demonstrates Git best practices:
- Branching (`main`, `dev`, `feature-ui`)
- Pull Requests and Merging
- Git Tags
- Using `.gitignore`

## Commands Used
- `git init`
- `git branch`
- `git merge`
- `git tag`
- `git stash`
- `git push`
